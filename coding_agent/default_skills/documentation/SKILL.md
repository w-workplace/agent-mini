Documentation conventions:
- Keep the README accurate: usage, configuration, requirements, and examples.
- Write docstrings for public modules/classes/functions that describe behavior
  and parameters, not just repeat the signature.
- Keep examples copy-pasteable and up to date with the current CLI/flags.
- Prefer a short "Quick start", then sections for configuration, features, and
  testing; use tables for requirement checklists.
- Update docs whenever you change behavior; do not leave stale instructions.
